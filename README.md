Implement Prime Number Analysis in Java

📌 Project Description

This project is developed as part of my Java Programming Internship at Veda Technology. The program checks whether a given number is prime and generates all prime numbers within a specified range.

🎯 Objectives

- Understand prime numbers and their properties.
- Practice Java methods and loops.
- Apply conditional statements and mathematical logic.
- Generate prime numbers within a given range.
- Improve algorithm efficiency.

🛠️ Technologies Used

- Programming Language: Java
- Input: Java Scanner class
- Concepts: Loops, conditional statements, methods, Boolean values, and operators.

⚙️ Features

1. Prime Number Checker: Determines whether a number is prime.
2. Prime Number Generator: Displays all prime numbers within a specified range.
3. Optimized Prime Checking: Checks divisors only up to the square root of the number.
4. Edge Case Handling: Correctly handles numbers less than 2.

💻 How It Works

1. The program accepts an integer from the user.
2. It checks whether the number is prime.
3. The program asks the user to enter the starting and ending numbers.
4. It checks each number in the range.
5. It displays all prime numbers found in that range.

▶️ Sample Output

Enter a number: 7
7 is a prime number.
Enter the starting number: 10
Enter the ending number: 20
Prime numbers in the range:
11 13 17 19

⏱️ Algorithm Complexity

- Time Complexity: O(√n) for checking one number.
- Space Complexity: O(1) auxiliary space for checking one number.

📚 What I Learned

- How to identify prime numbers using Java.
- How to use loops and conditional statements.
- How to create and call methods.
- How to optimize prime number checking.
- How to handle numbers less than 2.

🚀 Conclusion

This project helped me improve my Java programming skills and understand mathematical logic, loops, methods, and basic algorithm optimization.
